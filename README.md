# OKTOBER_FEST

Готовая статическая версия приглашения на Октоберфест.

Состав сборки:

- `index.html` — адаптивная страница и scroll-driven анимация;
- `oktoberfest-scroll.mp4` — видео для первого экрана;
- `assets/FortunaGothicFlorishC.ttf` — шрифт для заголовков.

## Публикация на Vercel

Загрузите содержимое этой папки как статический сайт.

- Framework Preset: `Other`
- Build Command: оставить пустым
- Output Directory: `.`

Видео управляется прокруткой: к финальному кадру фон затемняется, затем появляется hero-типографика. На телефоне используются отдельные размеры и безопасные отступы.
