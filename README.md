# OKTOBER_FEST

Статическое персонализированное приглашение на Октоберфест.

## Актуальные данные мероприятия

- Дата: **7.10**
- Начало: **18:30**
- Адрес: **Москва, ул. Ткацкая 5, ст. 7**

## Структура

- `index.html` — общая версия приглашения;
- `oktoberfest-scroll.mp4` — scroll-driven видео первого экрана;
- `assets/FortunaGothicFlorishC.ttf` — шрифт заголовков;
- `assets/invite.css` — общие стили;
- `assets/invite.js` — управление scroll-video;
- `guests/Фамилия-ИО/index.html` — персональные приглашения.

В тексте персональной страницы фамилия не используется: отображается только имя гостя. Фамилия и инициалы используются только в адресе персональной страницы.
